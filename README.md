# Independent website concept

A responsive website and owner-dashboard preview prepared by Gaurav Nazir for a potential small-business website project.

This is an independently prepared demonstration for All Hours Automotive Repair, Columbus, Ohio. It is not the official website and has not been commissioned or approved by the business. The form sends and saves nothing. All dashboard customers are fictional. Public business facts must be confirmed by the owner before any launch.

This repository publishes the static preview only. The separate deliverable includes a tested Flask/SQLite backend for private inquiry management, owner sign-in, status updates, business-detail editing and CSV export, plus deployment and handover instructions. GitHub Pages does not run that backend.

Original illustration and interface; no copied business photographs or customer quotes. No advertising trackers or third-party fonts.
